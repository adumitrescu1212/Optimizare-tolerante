## 📋 Despre proiect

Sistem de optimizare a toleranțelor bazat pe o arhitectură **multi-agent adversarială** cu **neuron fracționar**. Doi agenți software (Proiectantul și Testerul) interacționează iterativ pentru a găsi cel mai ieftin set de toleranțe care garantează funcționalitatea.

### Componente principale

- **🔵 Proiectantul** - Propune toleranțe (cost minim)
- **🔴 Testerul** - Verifică toate cele 64 de combinații extreme
- **🧠 Neuronul Fracționar** - Controlează agresivitatea ajustărilor
